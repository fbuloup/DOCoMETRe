Troubleshoots with ADwin Systems

See also ADwin DACQ Systems for the installation and the configuration of these systems.

Compilation fails on Windows : "Default ADBAsic Editor and compiler not found".

DOCoMETRe checks that the .bas extension is associated with a program. This association is created by the installer of the ADwin software: install (or install again) the ADwin software, or associate the .bas files with ADbasic in Windows. Also check the ADBasic compiler path field of the DACQ configuration.

Compilation fails on Linux or Mac OS.

  • Check in the general preferences of DOCoMETRe whether Docker or Wine is used (Use Docker (if not checked, Wine will be used)).
  • With Docker: the Docker daemon (Docker Desktop on Mac OS) must be running, and the ubuntu:adwin image must have been loaded (see Can I use ADwin systems with Mac OS ?). A container named adwin left by an interrupted compilation can be removed with docker rm -f adwin.
  • With Wine: check the Wine file location in the preferences and the ADBasic compiler path of the DACQ configuration. Wine can't be used since Mac OS 10.15.

The compiler can't find DOCOLIB or CALL*.INC files.

The ADBasic libraries path of the DACQ configuration must point to the DOCoMETRe ADbasic libraries of the installed version of DOCoMETRe. Update it with the Browse... button, in particular when DOCoMETRe warns that the libraries version used by the configuration differs from the current one. Also check that the Device type, the CPU type and the ADBasic version match your system and your ADbasic installation.

The trial doesn't start : "Impossible to boot ADwin : NOT_RESPONDING".

  • Check that the system is powered and connected to the computer.
  • Check the ADWin device IP address and ADwin device TCPIP port of the DACQ configuration (the Browse... button searches the reachable devices), and the network settings of the computer (same sub-network as the system).
  • Check that no other program (ADbasic, ADconfig, another DOCoMETRe) is using the system.

The trial doesn't start : "Impossible to boot ADwin : WRONG_BTL_FOR_CPU".

The Bootloader file path of the DACQ configuration gives a boot loader file made for another processor: use adwin9.btl with a T9 processor (ADwin Gold, ADwin Pro) and adwin11.btl with a T11 processor (ADwin Gold II, ADwin Pro II).

Some outputs or digital inputs don't behave as expected.

On ADwin Gold, Pro II and Pro DIO32 revision B modules, digital channels are configured as inputs or outputs by groups of 8: one output in a group makes the whole group an output. See ADwin Gold and ADwin Pro. Use the calibration and monitoring dialog to check the wiring.

Samples are lost during a trial.

Increase the buffer size (B.S. column) of the transferred channels, or decrease their sample frequency. The events diary of the trial reports the data losses.
