Startup and Help Menu

This page describes what happens when DOCoMETRe starts (choice of the workspace, Welcome page) and the commands of the Help menu.

Workspace

DOCoMETRe stores your experiments in a folder called the workspace: each experiment is a folder of the workspace. The workspace also holds the preferences of DOCoMETRe (in its hidden .metadata folder): each workspace has its own preferences.

At startup, the Workspace Launcher dialog asks for the workspace to use. Type the path of the folder, choose it with Browse..., or select one of the recently used workspaces in the list. The folder is created if it does not exist. When Use this as the default and do not ask again is checked, the dialog is no longer displayed and the last workspace is used at each start. To get the dialog back, check Show workspace selection dialog at startup in the general preferences, then restart DOCoMETRe (File > Restart).

A workspace can only be used by one DOCoMETRe at a time. If you choose a workspace already in use, an error message asks for another one. If DOCoMETRe has been stopped abruptly (crash, computer switched off), the workspace may be seen as still in use: if you are sure that no other DOCoMETRe is running with it, delete the file .metadata/workspace.locker of the workspace and start DOCoMETRe again.

On macOS, File > Launch another session starts another DOCoMETRe, which must use another workspace. On Windows and Linux, simply start DOCoMETRe again.

Linux: Wayland sessions

The OpenGL charts of DOCoMETRe (real time charts, data editor, XY and 3D charts) only work with the X11 display system. In a Wayland session (Ubuntu 22.04 and later, Fedora, WSL2 with WSLg...), DOCoMETRe therefore starts itself again automatically with the X11 backend of GTK (GDK_BACKEND=x11), which uses Xwayland. The splash screen may then be displayed twice: this is normal. Nothing has to be configured.

Welcome page

The Welcome page is displayed at the first start of DOCoMETRe, and at any time with Help > Welcome. It contains:

  • Overview: a short presentation of DOCoMETRe and of its main concepts (experiment, DACQ configuration, process, subjects, sessions and trials);
  • Tutorials: links that open the cheat sheets described below.

Close the Welcome page to reach the perspectives.

Help menu

Command Description
Welcome Displays the Welcome page.
Open help Opens this help. Its pages follow the light or dark theme of DOCoMETRe (see Appearance preferences).
Open Cheat Sheet... Opens a cheat sheet.
Check for updates Looks for a new version of DOCoMETRe on its update site and installs it (see below).
About DOCoMETRe Version and installation details of DOCoMETRe, with the address of its web site. Give the version when you report a problem.

Cheat sheets

A cheat sheet is a step by step guide displayed next to the perspective: each step explains what to do, and some steps offer a link that does it for you. Help > Open Cheat Sheet... lists the cheat sheets of the Introduction category:

  • Quick start: creation of a first experiment, with a DACQ configuration, a process and a subject with a session of ten trials;
  • ADBasic installation [Windows], [Mac OS X] and [Linux]: installation of the ADwin software needed to use ADwin systems (see ADwin Systems);
  • Arduino Installation: installation of the Arduino tools needed to use Arduino Uno boards (see Arduino Systems).

Updates

Help > Check for updates connects to the DOCoMETRe update site (http://fbuloup.github.io/docometre-release/p2/). When a new version is available, the wizard lists it: press Next, accept the licence, then Finish. DOCoMETRe asks to restart at the end of the installation. An Internet connection is needed, and the user must be allowed to write in the installation folder of DOCoMETRe.

New versions can also be downloaded from the DOCoMETRe web site and installed in place of the previous one: your workspaces are not modified.
