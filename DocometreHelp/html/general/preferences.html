Preferences

The preferences of DOCoMETRe are set in Options > Preferences... (on macOS, also in the application menu). The dialog lists the preferences pages on the left; the filter field at the top finds a page or a setting by its name. Restore Defaults sets back the default values of the displayed page, Apply saves them without closing the dialog.

Preferences are saved in the workspace: each workspace has its own preferences (except the language, which is common to all the workspaces). The DOCoMETRe pages are:

  • General;
  • Appearance: theme and language;
  • History: experiments history;
  • Math Engine, with its Matlab and Python sub-pages;
  • Systems, with its Default ADWin System and Default Arduino Uno System sub-pages.

Other pages may come from the Eclipse platform DOCoMETRe is built on (help, updates...).

Appearance

Setting Default Description
Theme System System follows the dark or light mode of the operating system, Light and Dark force a theme. The theme applies to the whole application: views, editors, charts, syntax coloring, and the pages of this help. DOCoMETRe proposes to restart, as the theme is fully applied only at startup.
Language System Language of the user interface: System (language of the operating system when it is available, English otherwise), English, French or Polish. DOCoMETRe proposes to restart with the new language. The help is only available in English.
When DOCoMETRe is started from the Eclipse IDE (development), it cannot restart itself with another language: set the -nl argument of the launch configuration instead.

History

Enables the experiments history and sets the author of the snapshots, the automatic snapshots and the optimization of the history storage. See Experiments history > Preferences.

Math Engine, Matlab and Python

Choice of the math engine used in the Analyse perspective (Matlab by default, or Python), loading of subjects, and locations, time outs and ports of each engine. See Math Engines > Preferences.

Systems

The Systems page only groups its sub-pages:

  • Default ADWin System: ADbasic compiler, boot (BTL) file, libraries and user libraries paths, ADbasic version, system type, CPU type, revision, IP address, port, device and module numbers, time out and global frequency;
  • Default Arduino Uno System: Arduino tools (arduino-cli or builder and avrdude), libraries and user libraries paths, revision, serial port, baud rate, global frequency and Delay time after serial print.

These values initialize each new DACQ configuration of the system. They can be typed in these pages, or copied from an existing configuration with the Set this configuration as default button of its General tab. The meaning of each value is given in DACQ Configuration > General tab, ADwin Systems and Arduino Systems.
