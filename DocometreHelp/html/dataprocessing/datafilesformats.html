Supported Data Files Formats

When a subject is loaded, DOCoMETRe reads its data files and builds its data model in the math engine. The following formats are supported:

Format Origin Math engines
Samples files (*.samples) Data acquired with DOCoMETRe: one file per recorded channel, in each trial folder. Python, Matlab
ADW files (*.adw) One file per subject, from DOCoMETRe version 2 or written by File > Export to ADW file(s). Imported in the experiment with File > Import... (type "Subject from ADW data file"). Python, Matlab
Optitrack CSV files (type 1 and type 2) Marker coordinates exported by Optitrack motion capture systems. Imported with File > Import... (types "Optitrack type 1" and "Optitrack type 2"). Python, Matlab
Data organized in columns (text files) Text files where each column is a signal, in a folder per subject (SubjectName/data_Conditions.txt). Imported with File > Import... (type "Data organized in columns"): the wizard asks for the separator of the columns and, if wanted, for the name and the sample frequency of each signal, which are written in the first two lines of the files. Matlab only

See also Import and export in the Design perspective chapter.
