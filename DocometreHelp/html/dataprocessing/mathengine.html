Math Engines

All the data of the Analyse perspective are held and processed by a math engine: Python or Matlab. DOCoMETRe starts the engine, sends it the data files of the subjects to load, the code generated from the processing files, and reads back the values to display. Only one engine is used at a time.

Requirements

  • Python: a Python 3 installation with the numpy, scipy, matplotlib and py4j packages (for example pip install numpy scipy matplotlib py4j). The complexity functions of the library (sample entropy, approximate entropy, multiscale sample entropy) also need the EntropyHub package.
  • Matlab: a Matlab installation with the Signal Processing Toolbox (used by filters and peaks detection).

Preferences

Engines are configured in Options > Preferences... > Math Engine:

Page Setting Description
Math Engine Math engine Engine started by the Start/Stop Math Engine button: Matlab (default) or Python. Change it only while the engine is stopped.
Always load subject from saved data When a subject has been saved, load it from its saved data without asking (see Loading subjects).
Padd with last value rather than zero Trials shorter than the longest one are completed with their last value instead of zeros (see Data model).
Python Python location Path to the Python executable (for example /usr/local/bin/python3 or C:\Python312\python.exe), or to the executable of a virtual environment where the packages are installed.
Python scripts location Folder of the DOCoMETRe Python scripts (DOCoMETRe.py). It is set automatically to the folder installed with DOCoMETRe: do not change it.
User scripts location Folder of your own Python user functions.
Python time out (seconds) Maximum time to wait for Python to start (60 s by default).
Java port number, Python port number Ports used by DOCoMETRe and Python to communicate (py4j library, 25333 and 25334 by default). Change them only if they are already used on the computer.
Matlab Show Matlab Window Shows the Matlab window when it is started by DOCoMETRe (useful to inspect variables or to see figures).
Matlab time out (seconds) Maximum time to wait for Matlab to start (180 s by default).
Matlab location, Licence Path to the Matlab executable and to its licence file. They can be left empty when Matlab is found automatically.
Matlab script location Folder of the DOCoMETRe Matlab scripts (loading of data files...). It is set automatically to the folder installed with DOCoMETRe.
User script location Folder of your own Matlab user functions; it is added to the Matlab path.

Starting and stopping the engine

The Start/Stop Math Engine button of the tool bar (also in the context menu of the Subjects view) starts the engine chosen in the preferences; a progress dialog is displayed while it starts, which may take a while for Matlab. Pressed again, it stops the engine: the loaded subjects are unloaded first, and a dialog lets you choose the modified subjects to save (see Saving subjects). Loading subjects, running processing files and opening charts require a started engine ("Please start a math engine first" otherwise).

DOCoMETRe asks to stop the math engine before it is closed.

Math engine console

The Math engine console, next to the Console view, sends commands directly to the engine and displays their result. Type an expression in the Command field and press Enter (or the Send button); Up and Down arrows recall the previous commands. Its tool bar clears the messages and locks the scrolling.

The console is useful to inspect the data of loaded subjects. Data are named Experiment.Subject.Signal.Element (see the Data model):

  • with Python, data are in the docometre.experiments dictionary, for example docometre.experiments["MyExp.S01.Force.SampleFrequency"]. Python commands of the console are evaluated as expressions;
  • with Matlab, data are in a structure named after the experiment, for example MyExp.S01.Force displays all the elements of the signal Force.

Figures can be drawn with Matlab or with Python Matplotlib: see Is it possible to use python Matplotlib or Matlab figures ?
