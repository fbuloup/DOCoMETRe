Batch Processing

A data processing file is built and tuned on one subject. A batch processing file (*.batchdataprocess) applies one or several data processing files to a list of subjects: for each subject, the name of the subject used in the processing files is replaced by the name of the processed subject.

Creating a batch processing file

Select the experiment (or a folder) in the Subjects view and use the New batch processing file button. A double click on the file opens its editor.

Batch processing editor

The editor shows an Introduction section and two lists:

  • Data Processing: the processing files to apply, in this order;
  • Subjects: the subjects to process, in this order.

Each list has the following buttons:

ButtonAction
AddOpens a dialog to select the processing files or the subjects to add.
DeleteRemoves the selected items from the list (the files are not deleted).
Up, DownChange the order of the selected items.
Enable/DisableA disabled processing is not applied; a disabled subject is not processed.
Run selected process (Data Processing list)Applies only the selected processing to the enabled subjects.

Options:

  • Load subjects automatically when necessary: subjects that are not loaded are loaded before being processed (from their saved data if "Always load subject from saved data" is checked in the Math Engine preferences, from their raw data otherwise). Without this option, subjects that are not loaded are skipped;
  • Save and unload subjects automatically when they were automatically loaded: once processed, these subjects are saved (if modified) and unloaded, which keeps the memory of the engine low when there are many subjects;
  • Run in main thread (override processes properties): runs all the processing in the main thread of Python, whatever the setting of each processing file (needed for Matplotlib figures).

The Save processing script as... button writes the whole code generated for all the subjects in a script file (choose a destination folder and a file name), for example to run it outside DOCoMETRe or to check it.

Running a batch processing

Start the math engine, select the batch processing file in the Subjects view (or activate its editor) and press Run selected data processes. For each enabled subject, in the order of the list, all the enabled processing files are applied in their order. Progress is shown in a dialog ("Loading subject...", "Processing subject...", "Saving subject...") and errors are written in the Console view.

Tips

  • Use the same signal names in all the subjects: processing files refer to signals by their names.
  • Put the processing that changes data (filters, cuts) and the one that computes markers and features in separate files: they can then be run again independently.
  • Put the export functions (Export Markers, Export Features) in a last processing file, or use Export data... once all the subjects are processed.
