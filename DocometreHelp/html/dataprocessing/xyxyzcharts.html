XY and 3D Charts

XY charts (*.chart) display a signal as a function of another one, for example the Y coordinate of a marker as a function of its X coordinate to see a trajectory, or a signal as a function of time. 3D charts (*.chart3D) display three signals in space. A chart file keeps its curves, its trials, its cuts and its scales: once configured on a subject, it can be opened again later, and its curves can come from several subjects.

Creating a chart

Select the experiment (or a folder) in the Subjects view and use the New XY chart or New 3D chart button. Give the name of the chart; it opens in its editor. The subjects whose signals are displayed must be loaded and the math engine started; the curves whose signals cannot be found are removed from the chart when it is opened.

Adding and removing curves

  • The Add curve button of the tool bar opens a dialog that lists the signals of the loaded subjects (type in the text field to filter them): select the signal of the X axis, then the signal of the Y axis (then of the Z axis for a 3D chart). For an XY chart, the X signal can be time.
  • Two signals can also be selected in the Subjects view and dropped onto an XY chart: the first one is the X signal, the second one the Y signal.
  • The Remove curve(s) button opens a dialog to select the curves to remove.

The signals of a curve are paired sample by sample: they must have the same sample frequency, otherwise the curve is refused. A curve is drawn for each selected trial.

Chart editor

On the right of the chart, the editor contains:

  • two tabs to choose what is displayed: Trials (list of the trials, with their category) and Categories (selecting categories selects their trials);
  • Graphical Front/End cuts values: number of samples removed at the beginning (front cut) and at the end (end cut) of the curves. Change them with the mouse wheel or type a value and press Enter. These cuts only apply to the chart, not to the signals;
  • Scales values (XY charts): X min., X max., Y min. and Y max. (type a value and press Enter), and Auto scale to fit the scales to the curves. Zooming or panning in the chart updates these values;
  • Show markers, marker Size and Show markers labels: markers of the displayed signals are drawn on the curves (they cannot be edited in a chart);
  • Same color for same category trials.

The tool bar contains the previous / next trial, add / remove curve, zoom and pan buttons, and, for 3D charts, turn left and turn right. Save the chart (File > Save) to keep its configuration.

Mouse and keyboard

With the "SWT + OpenGL v2" chart library (general preferences), the XY chart has the commands of the OpenGL data editor: wheel and rectangle zoom, right button pan, arrow keys, R to go back to the initial view (automatic scale), context menu. In 3D charts, drag with the left button to rotate the view, with the right button to pan, and use the wheel to zoom.
