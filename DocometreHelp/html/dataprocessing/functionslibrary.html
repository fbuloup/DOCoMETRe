Standard Functions Library

The following functions can be assigned to the function blocks of a data processing file (right click > Assign). Each one exists for Python and for Matlab; the code generated for the engine in use can be read in the Source code tab of the editor, and the code of each function in the Functions view (see User functions).

Unless otherwise stated, a function works on one input signal and on the trials given in its trials list (see Configuring a function). Functions that create a signal name it after the input signal followed by the output signal suffix; functions that place markers add them to the group whose label is given. Many functions work between two markers ("From" and "To"): the beginning of the signal, the end of the signal or a markers group.

Signals

FunctionDescriptionSpecific parameters
Modify Front Cut, Modify End Cut Change the front cut or the end cut of the signal: duration, at the beginning or at the end of the trials, that is not displayed in charts. Front cut or end cut, in seconds.
Modify Front Cut from marker, Modify End Cut from marker Set the front cut or the end cut of each trial at the time of a marker. Markers group.
Motion Distance Distance travelled along the curve formed by two signals (X and Y coordinates of a marker, for example), between two markers. Two input signals, From and To markers.
Motion Direction Direction of the motion, for each point of the curve formed by two signals, with respect to the starting marker. Two input signals, From and To markers.
Absolute value Absolute value of the signal (rectification).-
Derivative Derivative of the signal.-
1-D Interpolation Creates a signal whose samples between two times are replaced by an interpolation between these two points. Start time, stop time, method.
Duplicate Creates a copy of the signal.-
Change Sample Frequency Changes the sample frequency of one or several signals (for example when it was wrong in the data files). Signals, new frequency (Hz).
Replace samples values Replaces the values of a series of samples with the value of another sample. From index, to index, replacement index.
FFT Single sided spectrum of the signal: the result is a frequency domain signal, displayed as a function of frequency. -

Signals > Filtering

FunctionDescriptionSpecific parameters
Butterworth low pass filter (filtfilt), Butterworth high pass filter (filtfilt) Zero phase Butterworth filters (forward and backward filtering): the resulting order is twice the given one. Order, cut off frequency (Hz).
Butterworth low pass filter (filter), Butterworth high pass filter (filter) Causal Butterworth filters (forward filtering only, with a phase shift). Order, cut off frequency (Hz).
Remove pulses Suppresses pulses (artefacts) of given amplitude and duration. Maximum pulse duration (s), minimum pulse amplitude.
1D Median filter (medfilt1) Median filter.Order.

Markers

FunctionDescriptionSpecific parameters
Timer marker Marks the signal at a given time, or on its last sample. Time (s), Mark last sample.
Maximum, Minimum Marks the maximum (or minimum) amplitude of each trial between two markers. From and To markers.
Maxima, Minima Marks all the peaks (or all the minima) between two markers. From and To markers, height, threshold, distance, prominence.
Find amplitude backward, Find amplitude forward Searches, backward from a marker (to the beginning or the front cut) or forward from a marker (to the end or the end cut), the time when the signal reaches a given amplitude, and marks it. Amplitude value, From and To markers.
Threshold markings Marks all the times when the signal crosses a threshold. Threshold, bypass time (time after a detection during which a new detection is ignored), From and To markers.
Markers Group Transfert Creates a markers group on the input signal at the times of an existing markers group (of another signal, for example). Source markers group.

Features

FunctionDescriptionSpecific parameters
Mean Mean of the signal between two markers, for each trial (feature MEAN). From and To markers.
Markers difference Amplitude or time difference between two markers (M2 - M1), for each trial. Marker 1, marker 2, difference type, feature label, signal in which the feature is placed.

Features > Complexity

FunctionDescriptionSpecific parameters
Sample Entropy, Approximate Entropy, Multiscale Sample Entropy Complexity of the signal between two markers, stored as features. With Python, they need the EntropyHub package. From and To markers.

Export

FunctionDescriptionSpecific parameters
Export Markers, Export Features Write the selected markers groups (or features) of the loaded subjects in CSV text files, each time the processing is run. See also Exporting data. Markers or features to export (with a filter, Select all, Unselect all), destination folder (relative to the workspace or absolute path), separator.
