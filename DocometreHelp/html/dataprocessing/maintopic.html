Analyse Perspective

The Analyse perspective is the one used to inspect and process the data of an experiment once they have been acquired (or imported). Data are not processed by DOCoMETRe itself but by a math engine, Python or Matlab, started and driven by DOCoMETRe: subjects are loaded in the math engine, displayed in charts, processed with data processing files built with graphical blocks (filters, markers, features...), and the results are exported for statistical analysis.

The same processing or the same chart can be applied to several subjects: a processing approach is tuned on a test subject, then applied to all the subjects of the experiment with a batch processing.

This page describes the perspective as a whole. The following pages give more details:

  • Math engines: configuration of Python and Matlab, start and stop, math engine console;
  • Loading subjects: selection of the experiment, loading, unloading and saving of subjects, trials and categories, merging of subjects;
  • Data model: how signals, markers, features, categories and events are stored in the math engine;
  • Signal and category editors: display of signals, trials, cuts, markers and features;
  • Data processing files: building and running a processing;
  • Standard functions library: functions available in data processing files;
  • Batch processing: applying processing files to several subjects;
  • XY and 3D charts: charts of a signal as a function of another one;
  • User functions: extending the functions library, Functions view;
  • Exporting data: signals, markers and features to text files;
  • Supported data files formats.

Layout of the perspective

  • the Subjects view, on the left, shows the content of the selected experiment that is useful for analysis: subjects, data processing and batch processing files, XY and 3D charts, user functions and folders that contain some of them. A loaded subject can be expanded to show its signals, categories and events (see below);
  • the editors area, in the center, where signals, categories, processing files and charts are opened;
  • the Console view, under the editors area, where DOCoMETRe and the math engine write their messages (loading of subjects, errors of processing...);
  • the Math engine console, next to the Console view, which sends commands to the math engine (see Math engines).

The name of the selected experiment is displayed in the status bar. The Experiments view and the Functions view can be opened with Options > Show...

When a signal, category or chart editor is active, buttons are added to the tool bar: previous and next trial, add and remove curves (charts only), zoom in, zoom out, zoom to fit, pan up, down, left and right, and turn left and right (3D charts).

Subjects view

Before any selection, the Subjects view asks to select an experiment (Select experiment button). Once an experiment is selected:

  • a subject is decorated with an overlay when it is loaded in the math engine, and with another one when its loaded data have been modified and not saved yet;
  • a loaded subject can be expanded: its children are its signals, its categories (groups of trials) and its events, each one with its own icon;
  • a double click on a signal or a category opens it in the signal or category editor; a double click on a processing file, a chart or a user function opens its editor;
  • two signals selected in the view can be dragged and dropped onto an XY chart to add a curve (the first one is the X signal, the second one the Y signal).

The context menu of the view contains: New (data processing, batch processing, folder, XY chart, 3D chart, user function), Open..., Select experiment, Start/Stop Math Engine, Load/unload selected subjects, Run selected data processes, Rename..., Edit description, Refresh, Copy, Paste, Export data..., Merge data and Delete.

Typical workflow

  1. Configure the math engine once in the preferences (Options > Preferences... > Math Engine, see Math engines).
  2. Open the Analyse perspective, select the experiment and start the math engine.
  3. Load a subject and inspect its signals with the signal editor.
  4. Create a data processing file, add functions (filters, markers, features...) and run it on this subject. Check the results in the signal editor, adjust the parameters and run again.
  5. Save the subject if its processed data must be kept.
  6. Create a batch processing file to apply the processing files to all the subjects.
  7. Export markers and features for statistical analysis.
