Exporting Data

Results of the processing are exported to text files for statistical analysis or for other software. There are two ways:

  • the Export data... command, which exports on request the signals, events, markers or features of loaded subjects;
  • the Export Markers and Export Features functions of the library, which export them each time a data processing file (or a batch processing) is run.

Subjects can also be exported to ADW files (File > Export to ADW file(s), see Import and export), and whole experiments to archives.

Export data wizard

Load the subjects, then use the Export data... button of the tool bar (or File > Export data..., or the context menu of the Subjects view). The wizard asks for:

FieldDescription
Export destinationFolder where the files are written (Browse...).
Export typeSignal, Event, Marker or Feature.
Export in single file, Single file nameWhen checked, all the data are written in one file with the given name; otherwise one file is written per subject.
SeparatorSeparator of the columns (";" for example).
Data listAdd... opens a dialog that lists the elements of the chosen type in the loaded subjects; Remove selection and Remove all remove elements from the list.

Finish writes the files; a progress dialog shows the elements being written.

Files written

Without "Export in single file", each subject gets a file named Experiment.Subject.Type.txt (for example MyExp.S01.Feature.txt).

Signals: for each signal, a header and one line per trial:

Signal name;Force
Sample frequency;1000.0
Trial number;Category;Values
1;Session1.Pointing;0.12;0.15;0.17;...
2;Session1.Pointing;0.11;0.13;0.16;...

Markers and features: one line per trial, with the trial number and its category, followed by the selected markers (signal name, marker label, time and value) or features (signal name, feature label and value):

Trial Number;Session;Signal Name;Feature Label;Value
1;Session1.Pointing;Force;MEAN;2.31;Position;MEAN;12.7
2;Session1.Pointing;Force;MEAN;2.45;Position;MEAN;12.9

In a single file, signals are identified by their full names (Experiment.Subject.Signal).

Each line of markers or features can then be read as one observation by spreadsheet or statistics software.
