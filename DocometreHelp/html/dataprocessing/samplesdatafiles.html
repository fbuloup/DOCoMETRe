Samples Data Files

This is the default data file format: the format of the data acquired with DOCoMETRe. A samples file (*.samples) is a binary file that contains the values of one channel for one trial, as 32 bits floating point numbers (IEEE 754, little endian), without header. It is written in the folder of the trial (see Data files).

The file name holds the name of the channel. According to the options of the session, it can also hold a prefix, the name of the session and the trial number, separated by dots. Here are three examples of file names:

ChannelName.samples
ChannelName.SessionName.T32.samples
prefix.ChannelName.SessionName.T32.samples

When a subject is loaded, the trial number is read from the name of the trial folder (Trial n°32), the channel name from the file name, and the sample frequency from the DACQ configuration of the process associated with the trial.

You can find below a Matlab code to read this kind of file:

fileHandle = fopen(dataFileName, 'r');
data = fread(fileHandle, 'float32')';
fclose(fileHandle);

And below a Python code to read this kind of file using the Numpy library:

data = numpy.fromfile(dataFileName, dtype="float32")

Samples files can also be displayed without loading the subject with the data editor of the Design perspective.
