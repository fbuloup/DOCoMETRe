ADwin DACQ Systems

ADwin systems, made by Jäger Computergesteuerte Messtechnik GmbH, are real time systems with their own processor. DOCoMETRe supports the four variants below, which differ by their architecture (compact or modular) and their processor:

Variant Device type CPU type Processor
ADwin GoldGoldIT9, 40 MHz
ADwin Gold IIGoldIIT11, 300 MHz
ADwin ProProIT9, 40 MHz
ADwin Pro IIProIIT11, 300 MHz

Device type and CPU type are fields of the General tab of the DACQ configuration. They select the ADbasic compiler options and the DOCoMETRe library used to build the processes.

How DOCoMETRe works with ADwin

  1. When a process is compiled, DOCoMETRe generates its ADbasic source code (.BAS file in the BinSource folder next to the process) and runs the ADbasic compiler, which produces the binary file of the process.
  2. Before a trial, the system is booted with the boot loader file (*.btl) if needed, the parameters are sent and the binary file of the process is loaded in the system.
  3. During the trial, the process runs on the ADwin processor at the global frequency. Transferred channels and variables are read by DOCoMETRe through the Ethernet link, displayed and recorded; stimuli are sent to the system.

The communication with the system uses the ADwin Java driver shipped with DOCoMETRe: no other driver is needed to run trials. The ADwin software is only needed to compile the processes.

Installing the ADwin software

Download the ADwin software from the ADwin web site, uncompress it and run Setup.exe. It installs the ADbasic compiler, the ADconfig program and the boot loader files. Then:

  • run ADconfig to declare your system (IP address, device number);
  • run ADbasic once to configure the compiler for your system.

Step by step instructions are given by the cheat sheets of DOCoMETRe (Help > Cheat Sheets...):

Platform How the ADbasic compiler is run Help
Windows Natively. The .bas extension must be associated with ADbasic (done by the ADwin installer), otherwise the compilation fails with "Default ADBAsic Editor and compiler not found". Cheat sheet ADBasic installation [Windows]
Linux With Docker or Wine. Cheat sheet ADBasic installation [Linux] (Wine), and Can I use ADwin systems with Mac OS ? for the Docker image
Mac OS With Docker (any version) or Wine (before Mac OS 10.15 only). Can I use ADwin systems with Mac OS ? and cheat sheet ADBasic installation [Mac OS X]

On Linux and Mac OS, the choice between Docker and Wine is made in the general preferences of DOCoMETRe (Use Docker (if not checked, Wine will be used)). When Wine is used, give the location of the Wine executable in the same preferences page. When Docker is used, the Docker daemon must be running each time a process is compiled.

Connecting the system

ADwin systems are connected to the computer through Ethernet, usually with a direct cable. The default address of a system is 192.168.0.2 and its default port is 6543:

  • give the network interface of the computer a fixed address in the same sub-network (for example 192.168.0.1, mask 255.255.255.0);
  • check the connection with ADconfig, or with the Browse... button of the ADWin device IP address field, which searches the reachable devices of the sub-network.

Configuring the system in DOCoMETRe

All the fields of the General tab are described in DACQ Configuration. Pay particular attention to:

  • ADBasic compiler path: path of ADbasicCompiler.exe (for example C:\ADwin\ADbasic\ADbasicCompiler.exe on Windows);
  • Bootloader file path: the boot loader file must match the processor of the system (adwin9.btl for T9 processors, adwin11.btl for T11 processors). When the name of the file gives a processor that is not the one of the system, the boot is refused ("Impossible to boot ADwin : WRONG_BTL_FOR_CPU");
  • ADBasic libraries path: folder of the DOCoMETRe ADbasic libraries, shipped with DOCoMETRe. A warning is displayed when the configuration uses libraries older than the version of DOCoMETRe: update this path with the Browse... button;
  • ADBasic version: >=5 for current versions of ADbasic, <=4 for older ones;
  • ADWin device IP address and ADwin device TCPIP port: the values set in ADconfig;
  • Device type and CPU type: see the table above;
  • Global Frequency: frequency of the real time loop (default 2kHz). Some modules require a minimum frequency (15kHz for CAN modules used with a specified system type).

Supported modules

Modules are added in the Modules configuration section of the General tab, with their type, number and revision:

Module type Use
Analog inputs Acquisition of analog signals (±10V, ±5V or 0-10V, gains 1, 2, 4 or 8, single ended or differential), with calibration in physical units.
Analog outputs Generation of analog values, computed by the processes or read from stimulus files.
Digital inputs/outputs Triggers, switches, synchronization signals, stimulus files.
CAN Acquisition of Codamotion, Optitrack, gyroscope or time stamp data handled by DOCoMETRe, or any CAN communication written in the processes.
RS232 Serial communication with ICE systems or any serial device.

The parameters of each module and of its channels are described in Modules tabs. The way modules are numbered depends on the variant: see ADwin Gold / Gold II and ADwin Pro / Pro II.

Calibration and monitoring

The Calibration, monitoring button of the General tab loads a calibration program in the system (one for each variant) and shows the values of all the inputs and outputs. It is used to check the wiring and to compute the calibration values of the analog inputs: see Calibration and monitoring.
