ADwin Pro and Pro II

ADwin Pro and ADwin Pro II are modular systems: a processor module and input/output modules are plugged in a rack. Read ADwin DACQ Systems first for the installation of the ADwin software and the connection of the system.

Declaring the modules

Declare each module of the rack you use in the Modules configuration section of the General tab:

  • Module type: Analog inputs, Analog outputs, Digital inputs/outputs, CAN or RS232;
  • Module number: the address of the module in the system, as set on the module itself (see the hardware documentation of the module). Two modules of the same type must have different numbers;
  • Module revision: the revision of the module (A, B, C...), printed on the module.

For Digital inputs/outputs modules, the direction of the channels (Inp./Out. column) is programmed as follows:

  • ADwin Pro, module of revision A: channel by channel;
  • ADwin Pro, module of revision B, and ADwin Pro II: by groups of 8 channels (1-8, 9-16, 17-24 and 25-32). When one channel of a group is declared as an output, the whole group is configured as outputs: do not mix inputs and outputs in the same group. A usual choice is channels 1 to 16 as inputs and 17 to 32 as outputs.

The channel number of each channel is the number of the input or output on its module. The parameters of the modules and of their channels are described in Modules tabs. Check the wiring with the calibration and monitoring dialog.

Pro or Pro II ?

The Pro II processor is much faster: it allows higher global frequencies and more computations in each period of the real time loop. The processes are the same for both variants: to move an experiment from a Pro to a Pro II, change the CPU type and the boot loader file of the DACQ configuration, then compile the processes again. Make sure that the modules of the rack are supported by the Pro II processor (see the documentation of the modules).
