Arduino DACQ Systems

DOCoMETRe can use an Arduino board as a low cost real time system. The supported boards are the Arduino Uno R3 and Arduino Uno R4 WiFi, which can be extended with up to four ADS1115 16 bits analog to digital converters. Other Arduino boards (Uno R4 Minima, Due, Mega, Portenta, Teensy...) are not supported: see Planned systems.

How DOCoMETRe works with Arduino

  1. When a process is compiled, DOCoMETRe generates an Arduino sketch (.ino file in the BinSource folder next to the process) and compiles it with the Arduino tools.
  2. Before a trial, the compiled sketch is uploaded to the board when it has changed since the last upload, then the parameters are sent to the board, which acknowledges them.
  3. During the trial, a timer of the board calls the real time loop at the global frequency. The values of the transferred channels and variables are sent as text lines on the USB serial link, then displayed and recorded by DOCoMETRe.

Installing the Arduino tools

DOCoMETRe needs a command line tool to compile and upload the sketches. Two tools can be used:

Tool Boards Remarks
arduino-cli (recommended) Uno R3 and Uno R4 WiFi Required for the Uno R4 WiFi. Check Use command line tool in the DACQ configuration and give the path of the arduino-cli executable.
arduino-builder and avrdude Uno R3 only Tools of the Arduino IDE 1.x. Give their paths in Builder path and AVRDude path.

To install arduino-cli:

  1. download it from the arduino-cli installation page and uncompress it in a folder where you have all rights;
  2. install the cores of the boards you use, in a terminal: 
    arduino-cli core update-index
arduino-cli core install arduino:avr
arduino-cli core install arduino:renesas_uno
    (arduino:avr for the Uno R3, arduino:renesas_uno for the Uno R4 WiFi);
  3. if you use ADS1115 modules, install the ADS1X15 library (see ADS1115 Module).

The cheat sheet Arduino Installation (Help > Cheat Sheets...) gives links to the installation guides of the Arduino web site.

Connecting the board

The board is connected with a USB cable, which powers it and carries the serial link. The name of its serial port is given in the Serial port name field of the DACQ configuration (the Browse... button lists the available ports):

  • Windows: COM3, COM4... (see the Device Manager);
  • Mac OS: /dev/cu.usbmodem... or /dev/tty.usbmodem...;
  • Linux: /dev/ttyACM0, /dev/ttyACM1... Your user must be allowed to access this port: see Troubleshoots with Arduino Uno system.

Close any other program that uses the port (Arduino IDE serial monitor for example): DOCoMETRe could not open it.

Configuring the board in DOCoMETRe

All the fields of the General tab are described in DACQ Configuration. In particular:

  • Revision: R3 or R4_WIFI, see Arduino Uno R3 and R4 WiFi;
  • Arduino Uno Libraries path: folder of the DOCoMETRe Arduino functions, shipped with DOCoMETRe. A warning is displayed when it points to an older version of these functions;
  • Arduino SDK user libraries path: folder of additional Arduino libraries, only needed when they are not installed in the standard libraries folder of the Arduino tools;
  • Baud rate: speed of the serial link (default 2000000). High values are needed to transfer many samples;
  • Global Frequency: frequency of the real time loop (default 100Hz).

The preferences page Default Arduino Uno System also contains the Delay time after serial print, a delay added after each line sent to the computer. Increase it if samples are lost or corrupted on the serial link.

Limits

Compared with an ADwin system, keep in mind that:

  • all transferred values go through the serial link: the number of transferred channels multiplied by their sample frequency must stay compatible with the baud rate, and each line sent takes time in the real time loop. The workload displayed during a trial must stay well below 100%;
  • the Uno R3 has no floating point unit: floating point computations are slow and there is no calibration tool. The time base of the R3 is a ceramic resonator, less stable than a crystal: see Timing consideration;
  • the analog outputs are PWM outputs, and some functions of the processes are only available for ADwin (stimulus, filters, serial port functions...): see the functions table of DACQ Process.
