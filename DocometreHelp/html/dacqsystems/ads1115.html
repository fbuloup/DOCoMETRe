ADS1115 Module

The ADS1115 is a ΔΣ analog to digital converter with four multiplexed channels, a programmable gain amplifier and an I2C interface. It can be added to an Arduino Uno (R3 or R4 WiFi) when the resolution of the analog inputs of the board is not sufficient. Up to four ADS1115 modules can be used on the same board.

15 or 16 bits ?

The ADS1115 is a 16 bits converter, but its result is signed: it measures voltages from -FS to +FS (FS being the full scale given by the gain). DOCoMETRe uses its inputs in single ended mode, each channel being measured against GND: only positive values are then used, from 0 to 32767, which gives 15 useful bits. This is why the module is named "Four 15bits Analog inputs" in the DACQ configuration.

Near 0V, noise can give small negative values (-1, -2...): they are kept as negative values in the variables of the process and in the data files.

Installing the ADS1X15 library

The generated sketches use the ADS1X15 library of Rob Tillaart, which must be installed once. With arduino-cli, run in a terminal:

arduino-cli lib install ADS1X15

You can also install it with the library manager of the Arduino IDE, or download it from GitHub. If the library is installed in a folder that is not the standard libraries folder of the Arduino tools, give this folder in the Arduino SDK user libraries path field of the DACQ configuration. If the compilation fails with "ADS1X15.h: No such file or directory", see Troubleshoots with Arduino Uno system.

Wiring

ADS1115 Arduino Uno
VDD5V (or 3.3V)
GNDGND
SCLSCL (same signal as A5)
SDASDA (same signal as A4)
ADDRGND, VDD, SDA or SCL, to choose the I2C address
A0 to A3the signals to acquire, between GND and VDD

The ADDR pin gives the address of the module on the I2C bus:

ADDR connected toI2C address
GND0x48
VDD0x49
SDA0x4A
SCL0x4B

Each module of the same board must have its own address. The I2C bus uses pins A4 and A5 (the Qwiic connector of the R4 WiFi is not used): do not use the analog inputs AIN4 and AIN5 with ADS1115 modules. The voltage applied to an input must never be below GND or above VDD, whatever the gain.

Configuring the modules

Add the modules in the Modules section of the General tab of the DACQ configuration. Each module gets its own tab with:

  • Address: the I2C address of the module (0x48, 0x49, 0x4A or 0x4B), which must match its wiring;
  • Mode: 0 for continuous mode, to acquire one channel only; 1 for single shot mode, recommended to acquire several channels;
  • Conversion time: from 0 (about 124ms, less noise) to 7 (about 2.7ms, fastest). Use 7 unless the signals are too noisy.

For each channel used, the Gain sets the full scale of the input:

Choose the highest gain whose full scale is above the maximum voltage of the signal. The calibration values (Unit, UMax, UMin, AMax, AMin) convert the values in physical units, as for the analog inputs of the board.

Sample rates

With DOCoMETRe, it is possible to acquire about 600Hz on one channel in continuous mode, and about 300Hz per channel in single shot mode. The conversions are done during the real time loop: check the workload and choose a global frequency and sample frequencies compatible with these values.
