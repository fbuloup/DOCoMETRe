DOCoMETRe

DOCoMETRe stands for "Dispositif d'Observation et de COntrôle du Mouvement En Temps Réel". It is a multiplatform software (Windows, Mac OS and Linux) developed at the Institut des Sciences du Mouvement in Java, using the Eclipse RCP framework.

Its aim is to make it easier to design and run human movement science experiments. It covers the whole chain, from real time data acquisition to deferred data processing:

  • Data acquisition and real time control: DOCoMETRe drives ADwin (Gold, Gold II, Pro and Pro II) and Arduino Uno (R3 and R4 WiFi) systems. Inputs, outputs, variables and real time charts are described graphically in data acquisition configurations, and the real time algorithm is built in processes, without writing low level code.
  • Experiment management: the root concept of the software is the Experiment. An experiment contains data acquisition configurations, processes and subjects. Each subject has one or more sessions, and each session is a set of trials. Each trial runs a process to collect data.
  • Data processing: once data have been acquired or imported, signals can be inspected and processed (e.g. filtering, points marking or features computation) with a math engine, Python or Matlab, driven by DOCoMETRe. The results can then be exported for statistical analysis.

The work is organised in three perspectives: the Design perspective to prepare the experiment, the Acquire perspective to run it, and the Analyse perspective to process the data.
