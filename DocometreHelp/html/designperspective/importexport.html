Import and Export

DOCoMETRe keeps its experiments in a workspace folder, but also adds to each file and folder properties that are not stored in the files themselves (types, associations between processes and configurations, trials modes and states, descriptions...). This is why experiments must be exchanged with the export and import commands described below, rather than by copying folders with the file manager of the system.

Import wizard

Select, in the Experiments view, the resource that will receive the imported files, then use File > Import... (or the Import button of the tool bar). The wizard shows:

  • Destination: the selected experiment, folder or subject (or the workspace root when nothing is selected);
  • Type: the type of resource to import. The proposed types depend on the destination (see below);
  • Parent folder: the folder of the disk that contains the files to import (Browse... to choose it);
  • a tree of the files and folders of the parent folder that match the chosen type: select the ones to import (several can be selected), then press Finish.

Files cannot be imported from inside the current workspace: use copy and paste in the Experiments view instead (see below).

What can be imported

Destination Type Result
Nothing selected (workspace root) Experiment (*.zip, *.tar) Creates a new experiment from an archive made with Export Experiment, with all the DOCoMETRe properties of its resources. The experiment takes the name of the archive: import is refused if an experiment with this name already exists.
Experiment or folder DACQ Configuration Copies *.daqconf files. Their system (ADwin or Arduino UNO) is detected automatically.
Experiment or folder Data acquisition process Copies *.process files. If the label of an imported process shows "No associated DAQ file", associate it with a configuration with the Associate with... sub-menu of the context menu.
Experiment or folder Data processing Copies *.dataprocess files.
Experiment or folder Subject from ADW data file Creates a subject from each selected *.adw file (see ADW data files).
Experiment Subject of a tree structure - Optitrack type 1 or type 2 Creates subjects and sessions from folders of Optitrack CSV files (type 1: SubjectMCond/data_N.csv, type 2: SubjectM/trial_N.csv); select the subjects folders (see Optitrack CSV files).
Experiment Subject of a tree structure - Data organized in columns Creates subjects from folders of text files whose columns are signals (SubjectName/data_Conditions.txt); select the subjects folders. Dialogs ask for the separator of the columns and, if wanted, for the name and the sample frequency of each signal.
Subject Sessions configuration file (*.ini, *.txt, *.properties) Creates the sessions and trials described in the file, with their start and validate modes and their processes (see What is file format for sessions importation ?). A session that already exists in the subject is not imported.

Subjects created from ADW, Optitrack or column data files are then processed in the Analyse perspective (see the Data Processing chapter and Supported data files formats).

Exporting an experiment

File > Export Experiment... saves an experiment in an archive, for example to back it up, to send it to a colleague or to move it to the computer that runs the real time system. The wizard asks for:

  • the experiment to export;
  • the destination file (Browse... to choose it; it must not exist yet);
  • the options: Save in zip format or Save in tar format, Compress, and Export with data (checked by default; when unchecked, data files - samples, ADW, Optitrack, column, CSV and saved data files - are not included, which gives a much smaller archive with the configurations, the processes, the protocol and the diaries);
  • Export only selected subjects: when checked, select in the list the subjects to export.

The archive contains the files of the experiment and a properties file that holds the DOCoMETRe properties of each resource; they are restored when the archive is imported in another workspace (Import... with nothing selected, type Experiment). The name of the archive becomes the name of the imported experiment: do not rename an exported archive, as this could lead to importation errors.

Exporting subjects to ADW files

When subjects are selected, File > Export to ADW file(s) writes the samples files of each selected subject in one ADW file (SubjectName.adw) in a folder chosen with a dialog. An existing file is not overwritten (an error is written in the Console view). This format can be read by other analysis software (see ADW data files).

Processed data of loaded subjects (signals, events, features) are exported from the Analyse perspective with File > Export data... (see the Data Processing chapter).

Copying resources inside the workspace

Inside the workspace, configurations, processes, subjects, sessions, trials and folders are duplicated with Copy and Paste in the Experiments view (Ctrl+C / Ctrl+V, Cmd on macOS), even between experiments; their DOCoMETRe properties are copied too. When folders are pasted, a dialog asks whether diaries and data files must be copied as well: answer No to reuse a protocol (subjects, sessions and trials with their processes) for new acquisitions. When resources with the same names already exist in the destination, DOCoMETRe asks whether they must be overwritten.
