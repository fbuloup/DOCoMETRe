Data Editor

The data editor displays the content of samples files (*.samples), that is the signals recorded in a trial or in a process test, as a function of time. It is a quick way to check acquired data without loading the subject in the Analyse perspective. The data editor does not modify the files.

Opening signals

  • Double click on a samples file in the Experiments view (or select it and use File > Open). Each samples file opens its own editor.
  • To display several signals in the same editor, drag other samples files from the Experiments view and drop them onto the opened editor. The name of the editor is then followed by "(...)" and its tooltip lists the displayed files.

Samples are read as 32 bits floating point numbers. To build the time axis, the data editor needs the sample frequency of the signal: it is found in the DACQ configuration of the process associated with the trial (or with the process test). If it cannot be found (file copied from elsewhere, channel renamed, process no longer associated...), a dialog asks for the sample frequency; Cancel does not display the signal. The number of samples read is written in the Console view.

Two versions of the data editor

DOCoMETRe uses one of two data editors, according to the real time chart library chosen in Options > Preferences... > General ("Real time chart library", restart needed after a change):

  • with "SWT + OpenGL v2", the OpenGL data editor (GLDataEditor) is used: it is fast, even with very long signals, and offers more display options;
  • with "SWT" or "SWT + OpenGL v1", the SWT data editor (DataEditor) is used.

In both cases, the main tool bar gets the following buttons while a data editor is active: Zoom in, Zoom out, Autoscale (back to the whole signals), Left, Up, Down and Right panning. Data editors still opened when DOCoMETRe is closed are opened again at the next start, with their signals and their view.

OpenGL data editor

All the signals are displayed from t = 0; the horizontal axis covers the duration of the longest signal and the view automatically fits the data. Mouse commands:

Mouse Action
Wheel Zooms in or out on both axes, around the point under the mouse.
Left button + drag Rectangle zoom: the rectangle drawn with the mouse becomes the view when the button is released. A very narrow rectangle zooms on one axis only.
Right button + drag Moves (pans) the view.
Left double click (cursor displayed) Freezes a static cursor on the current point: the differences Δx and Δy between the moving cursor and the static cursor are then displayed. Another double click moves the static cursor.
Right click Opens the context menu (see below).

Keyboard commands (click in the chart first to give it the focus):

Key Action
CShows or hides the cursor. The cursor follows the point of a curve at the abscissa of the mouse and its coordinates are displayed on the axes.
Tab, Shift+TabCursor on the next / previous curve.
Arrow keysPan by a tenth of the view.
U or BackspaceBack to the previous view (undo zoom).
RBack to the initial view.
EscCancels the rectangle being drawn.
NShows or hides the legend.
VShows or hides the last value of each curve.
PShows or hides the points (samples).
G, A, LShow or hide the grid, the axes, the tick labels.
DEnables or disables the decimation (only part of the points are drawn when they are too close on the screen).
FShows or hides the frame rate.

The context menu gives the same commands: show / hide the cursor, remove the static cursor, show / hide the legend, legend inside or below the chart, last value, points, grid, axes, tick labels, frame rate, decimation, undo the zoom and reset the view.

SWT data editor

Mouse / key Action
Left button + drag Rectangle zoom.
Arrow keys Pan by a tenth of the view (a hundredth with Ctrl).
Tab Cursor on the next curve.
Double click (cursor displayed) Places the marker on the curve of the cursor.
Esc Hides the cursor and the marker, cancels the rectangle being drawn.
Right click Context menu: Show legend, Legend position (top or bottom), Adjust X, Y scales (or X scale, or Y scale only), Show grid, Show axis, Show cursor, Series thickness, Show samples, Symbol samples (square or round) and Symbol size.

When the cursor is displayed, the status bar gives the coordinates of the cursor, of the marker and their difference (Δ). The cursor is displayed at opening when "Show cursor (Time charts)" is checked in the general preferences.

Going further

The data editor only displays raw samples files. To filter signals, place markers, compute features or export data, load the subject in the Analyse perspective (see Loading subjects and Signal and category editors).
