What is images file format ?

Images files (*.images) give the images displayed by image charts in the Acquire perspective, one image per trial. An image chart reads, in the folder of the session of the running trial, the images file whose name is its generic images files name followed by .images : with the generic name stimuli, each session must contain a file stimuli.images. Each session can thus have its own list of images, and several image charts can use different images files.

An images file is created with File > New > Images file... when a session is selected, and edited with the images files editor. It is a simple text file that can also be written elsewhere :

  • "#" starts a comment, until the end of the line : a line can be a comment, or a comment can follow the path of an image;
  • comment lines and empty lines are ignored;
  • the first uncommented line gives the image of trial 1, the second one the image of trial 2, etc.;
  • when the session has more trials than uncommented lines, the last line is used for the remaining trials;
  • each line contains the path of an image file, either absolute or relative to the workspace folder. A path can't contain "#";
  • supported formats are those read by SWT : PNG, JPEG, BMP, GIF, ICO and TIFF.

For example, with images stored once in a folder images of the experiment MyExperiment :

# Images of the session (one line per trial)
MyExperiment/images/target_left.png     # trial 1
MyExperiment/images/target_right.png    # trial 2

# Last line : trials 3 and following
C:\Stimuli\target_center.jpg

Trial 1 displays <workspace>/MyExperiment/images/target_left.png, trial 2 <workspace>/MyExperiment/images/target_right.png, and trials 3 and following C:\Stimuli\target_center.jpg.

Errors

When the images file is missing or has no uncommented line, or when the image of the trial is not found or can't be read, an error message is displayed in red in the chart and written in the error log (with the number of the line in the images file, comments included). The trial is run anyway.

When a process is tested on its own, the images file is searched in the folder of the process, and its first uncommented line is used.

Images files of previous versions

First versions of image charts used a text file whose generic name included its extension (images.txt). Such a generic name is still accepted : when it ends with .txt, the file is searched with this name. Rename these files with the .images extension (and remove .txt from the generic name) to edit them with the images files editor.
